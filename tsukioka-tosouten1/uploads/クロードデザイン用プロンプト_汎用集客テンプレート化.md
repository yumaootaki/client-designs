# 依頼内容:既存テンプレートを「汎用・集客重視の建設業デモサイトテンプレート」に作り替える

## 0. 前提

添付したZIP(株式会社エンジョイホーム／塗装業／採用重視の14ページテンプレート一式)を土台に、**新しいマスターテンプレート**を作成してください。これは特定クライアントの納品物ではなく、**今後さまざまな建設関連業種(塗装・外構・電気設備・内装リフォームなど)の商談で使い回す汎用テンプレート**です。

着手前に、CLAUDE.md記載の「差し替え計画の承認」プロセスに則り、以下の変更方針をこのテンプレート自体に反映してください(個別クライアントの固有情報への差し替えはこの時点では行わない＝サンプルの質感は温存)。

**変更の軸:採用重視 → 集客・問い合わせ重視**

## 3. 汎用化(業種非依存化)の指針

- 現在の本文は「株式会社エンジョイホーム(塗装)」の作り込み文章が品質見本として残っています。**文章の質感・情報の厚みはそのまま活かしつつ**、業種固有すぎる語(外壁塗装・屋根塗装・下地補修など)は、他の建設系業種でも読み替えやすい書き方に調整してください(完全なプレースホルダ化はしない、というこれまでの方針は維持)。
- `業務案内.dc.html`に混入している旧々案件(法面工事)由来の語が残っていれば、この機会にあわせて除去してください。
- 配色トークンの方針は下記4-1を参照(ブラウン系から青系に変更)。

## 4. デザイン・演出仕様(参考:河合塗装 https://8hands.jp/ ※スクショ添付)

**適用範囲:TOP・業務案内(親)・施工の流れの3ページのみ。** それ以外のページ(会社概要・スタッフ紹介・施工実績・FAQ・お問い合わせ・料金・対応エリア・ブログ・プライバシーポリシー等)は現行テンプレートの標準的なレイアウトのままとし、演出を持ち込みすぎない。ただし全体のトンマナ(配色・角丸・余白感)は統一する。

### 4-1. 配色
- デフォルトは参考サイトに近い**青×ベージュ系**にする。
- ただし`theme.css`の6変数構造(`--c-ink` `--c-brand` `--c-brand-2` `--c-cream` `--c-cream-2` `--c-beige`)は維持し、**値だけ**青系に差し替える。案件ごとにこの6変数を変えるだけで配色を切り替えられる、という現行の仕組みは崩さないこと。

### 4-2. TOPページ:ヒーロースライダー(刷毛ワイプ切り替え)
- 複数のヒーロー画像を、刷毛で上から塗るような不規則な境界線のワイプ演出で切り替えるスライダー。
- 単純な四角いワイプではなく、筆で塗ったようなかすれ・ギザギザのある輪郭を再現したい。SVGのブラシストローク形状をclip-path/マスク画像として用意し、次のスライドをそのマスクで重ねてアニメーションさせる方式を想定。
- 自動切り替え(数秒間隔)+手動ページネーション(ドット等)。
- `prefers-reduced-motion`時はフェード程度の簡易切り替えに落とす(アクセシビリティルール§11準拠)。

### 4-3. スムーススクロール
- ページ全体に慣性のある滑らかなスクロールを導入。
- 実装は軽量なスムーススクロールライブラリ、もしくは補助JSでの実装で可(過度に重くならないものを優先)。
- `prefers-reduced-motion`時は通常スクロールに戻す。

### 4-4. スクロール連動テキストカラー演出
- 見出しや強調コピーが画面内に入る/スクロールが進むのに合わせて、文字色が(グレー→ブランドカラー等)変化していく演出。
- 「こだわり」紹介セクションやTOPのキーメッセージなど、**要所のみに限定**して使用(多用しない)。
- 実装はIntersectionObserverまたはスクロール連動アニメーション手法(scrub型)で、文字単位/行単位に色変化を付ける想定。

### 4-5. その他、参考サイトから取り入れたい演出
- セクション間の波形(SVG)区切り:上記3ページ内のセクション境界に使用。
- 手描き風の注釈(「One / Two / Three」のような手書き風フォント・丸囲み数字):特徴紹介・こだわりセクションに使用(フォントはライセンス確認の上で選定)。
- 円形アイコンバッジ:業務案内ページのサービスメニュー・付帯工事一覧などに使用。

### 4-6. 屋根型シルエットの導線ギャラリー(新規要素)
- 参考サイトの「屋根の三角形シルエットで事例を並べる」レイアウトを、**施工事例ではなくサイト内主要ページへの導線(ナビゲーションカード)として**採用する。
- TOPページに設置し、「業務案内」「施工の流れ」「料金の目安」「対応エリア」「施工実績」等へのリンクを屋根型シルエットのカードで並べる。
- 施工実績ページ自体の見せ方(一覧グリッド)は現行のまま変更しない(🔒ロック領域のため)。

## 5. 遵守事項(CLAUDE.mdのルールは全て維持)

- 動的部分のロック(施工実績・TOP新着情報帯・BLOGカード)の構造・クラス変更は禁止のまま
- 創作の禁止(在籍者属性・手当額・受賞歴・創業年などの固有事実主張は出典がなければ載せない)は新規ページ(特に「料金・お見積もりの目安」)でも厳守
- モバイルファースト・アクセシビリティ(WCAG 2.1 AA)・改行制御ルールは維持
- ファビコン/OGPは汎用テンプレのため今回は変更不要
