# 配色トークン（色対応表）— 田中工業

> このテンプレ専用。他案件へ流用しない。
> Design Component（インラインCSS）方針のため `:root` 変数が使えない。配色は「**旧値 → 新値の一括置換**」で切り替える。
> 対象＝ルート直下の全 `*.dc.html` ＋ `add.css` ＋ `_preview_トップページ（遷移可能）.html`。

## ブランド色（置換対象）

| 役割 | 現行HEX | rgba表記（別途置換） | 主な使われ方 |
|---|---|---|---|
| ネイビー（プライマリ） | `#1B3A5B` | `rgba(27,58,91, a)` | 英字ラベル・見出しアクセント／CTA帯背景／罫線・枠線／明背景ボタン地色／NEWS帯の日付 |
| 濃紺（ダーク面） | `#0B1D30` | `rgba(11,29,48, a)` | ヘッダー／フッター／モバイルメニュー／下層ヘッダー／写真の暗幕・ドロップシャドウ／イエローボタンの文字色 |
| イエロー（アクセント／CTA） | `#F2C200` | — | CTAボタン地色（文字は `#0B1D30`）／大きな数字／`:focus-visible` アウトライン／ヒーローの筆致／ナビ現在地 |
| イエロー hover | `#ffd633` | — | イエローボタンのホバー時地色 |
| 筆致の中間層 | `#E5B800` / `#FFDE4D` | — | ヒーロー筆致の筆芯・かすれ筋（イエローの明暗2段） |

### コントラスト
- イエロー地 `#F2C200` × 濃紺文字 `#0B1D30` ＝ 十分なコントラスト（CTAの既定）
- ネイビー地 `#1B3A5B` × 白文字 `#fff` ＝ 本文可
- 濃色面の大きな数字・リンク文字＝`#F2C200`
- 明背景の英字ラベル・見出しアクセント＝`#1B3A5B`（`#F2C200` は明背景の本文に使わない）

## 中立色（さわらない）

| 色 | 用途 |
|---|---|
| `#FFFFFF` / `#fff` | 背景・白文字・カード地 |
| `#1A1A1A` | 本文の基本文字色 |
| `#333` / `#444` / `#555` | 本文の補助文字色 |
| `#1F2A3C` | ヒーローのリード文 |
| `#F4F6F8` | 補助背景（セクション地） |
| `rgba(255,255,255, a)` | 濃色面上の白系文字・罫線 |

## 置換手順
1. HEXは大小無視で検索。
2. `rgba(27,58,91,…)` / `rgba(11,29,48,…)` も新色のRGBへ変換して置換。
3. 置換後、白文字×濃色面＝4.5:1以上、イエローボタン×濃紺文字を確認（共通ルール §2）。
4. `run_script` は日本語ファイル名を扱えない。日本語名ページはASCII名へコピー → 置換 → 元名へ戻す。

> ⚠️ `add.css` は CMS動的パーツ（NEWS帯 `design-parts-52`／施工実績カード `parts228`）の見た目専用。**色だけ**を置換し、セレクタ・構造は触らない（共通ルール 0-5＝ハードロック）。
