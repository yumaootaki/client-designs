## 2. コンセプト

**「水・電気・浄化槽。設備工事を、一社で。」**
工務店の「設備部門」になれる会社、というポジション。
発注窓口の一本化・各自治体の指定工事店としての申請対応・有資格者による自社施工が差別化の軸。

- 法人に対して：堅実で信頼できる、きちんとした会社に見えること

- 全体：地方の設備屋っぽさを脱し、「企業らしさ」と「いまっぽさ」を両立

## 3. デザイントークン

### カラー（現行の青と黄色を継承しつつ引き締める）

| 役割 | HEX | 用途 |
|---|---|---|
| Deep Navy（メイン） | `#0B2E59` | ヘッダー文字、見出し、濃色セクション背景、フッター |
| Water Blue（サブ） | `#1F5FAF` | リンク、アイコン、図版の線、ホバー |
| Signal Yellow（アクセント） | `#F7C21B` | **法人向けCTAボタン・配管ラインモチーフ・重要ラベルのみ**。面積は全体の5%以下 |
| Ink | `#1A2230` | 本文 |
| Mist（ベース） | `#F4F6F9` | 交互セクション背景 |
| Pipe Gray（線） | `#D5DCE5` | 罫線、表、カード枠 |

- 黄色は面で塗らず「線・ボタン・マーカー」に限定（工事現場の注意色を上品に使う）
- 写真はネイビーのデュオトーン／やや寒色寄りのトーンで統一

### タイポグラフィ

- 和文：**Zen Kaku Gothic New**（見出し700／本文400〜500）
- 欧文・数字：**Barlow Semi Condensed**（見出し英字・数字カウンター・年表の年号）
- 見出しサイズ目安：H1 44–56px／H2 30–36px／H3 18–20px／本文 16px・行間1.9
- 英字見出しは大きく細身で、和文見出しの補助として使う（全見出しの上に英字ラベルを付けるような多用はしない）
- 1行の文字数は最大40字程度

### レイアウト

- コンテナ幅1200px、12カラム、左揃え基調（CTAセクションのみ中央）
- 角丸は小さく（ボタン4px、カード2〜6px）、影は最小限。直線的でかっちりした構成
- 余白は広め（セクション上下 120px 前後、SPは 72px）

### 一点突破のモチーフ：配管ライン

- 黄色の細いライン（2px）が、配管のように **直角に曲がりながらセクション間やステップをつなぐ**
- 使いどころ：TOPヒーローの下端 → 「お悩み→解決」、取引開始までの流れ、沿革の年表、採用の1日の流れ
- 動きはスクロールに合わせてラインが伸びる演出を **1箇所（取引開始までの流れ）だけ** に集中。他の演出は控えめに
- `prefers-reduced-motion` 時は静止表示

### TOPヒーロー動画

- 素材：Gemini生成の10秒動画（`hero.mp4`）。デモでは同ファイル名で差し込む想定
- 実装：`<video autoplay muted loop playsinline poster="hero-poster.jpg">`。全幅・高さ100svh（SPは80svh）、`object-fit: cover`
- **AI動画の粗さを抑える処理**
  - ネイビー（`#0B2E59`）の半透明オーバーレイ（不透明度50〜60%）を重ね、キャッチの可読性を確保
  - `filter: saturate(.6) contrast(1.05)` で彩度を落とし、サイト全体の寒色トーンに合わせる
  - `playbackRate = 0.8` で動きを落ち着かせる（10秒 → 約12.5秒ループ）
  - ループのつなぎ目はネイビーへ0.6秒フェードアウト→フェードイン
  - 文字と黄色の配管ラインを前面に出し、動画は「雰囲気の背景」に徹させる
- フォールバック：1フレーム目を書き出したポスター画像を用意。`prefers-reduced-motion` と SPの省データ時は静止画表示
- 右下に小さな一時停止／再生ボタン（アクセシビリティ対応）
- 動画ファイルは H.264 / 1920×1080 / 3MB以下に圧縮、WebM版も併用
