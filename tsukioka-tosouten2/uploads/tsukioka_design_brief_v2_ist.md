# 月岡塗装店 サイトリニューアル Claude Designブリーフ【パターンB / ISTテンプレート準拠】

パターンA(`tsukioka_design_brief.md`/汎用集客テンプレートlead-gen-template準拠)に対する、もう一つのデザイン方向性案。
添付いただいた株式会社イスト様サイトのテンプレート一式(`css/style.css`・`partials/header.html`・`partials/footer.html`等)の構造をベースに、月岡塗装店用へ組み替える。

## 1. 案件概要(パターンAと共通)
- クライアント: 有限会社月岡塗装店(埼玉県新座市、外壁塗装・屋根塗装、昭和52年創業/38年実績)
- 現URL: https://tsukiokatosouten.com/
- 主軸ニーズ: 受注(集客特化)。現状は自社案件3割・下請け7割 → 逆転が目標
- 現状の最大課題: 平均滞在時間20秒。情報不足による比較検討層の離脱
- 強み: 成約率90%、下塗り2〜3回など専門的な施工へのこだわり、38年の実績、近隣配慮の徹底
- ページ構成: 既存7P(リライト)+新規7P=全14P(詳細はワイヤーフレーム`tsukioka_wireframe_v2_ist.html`参照)

## 2. このパターンの世界観
ベーステンプレートのコンセプトは「紙の質感 × 写真コラージュ × 縦横の余白」。右サイドの縦レールナビ・全画面メニューオーバーレイ・丸型固定CTA(fab)・スプラッシュ画面・視差スクロールする写真コラージュヒーロー・筆記体ラベル見出しという、パターンA(上部ナビ+刷毛ワイプ演出)とは構造から異なる上品な世界観。

**壁打ちでの合意事項**:
- 配色は青の濃淡のみに絞り、サブアクセント(元テンプレのテラコッタ)は使わない
- テンプレ本来の上品さは活かしつつ、写真を大きく・やや荒くトリミングすることでご要望の「インパクト」を足す方向で調整する

## 3. デザイントークン(元テンプレからの差し替え)
| 項目 | 元テンプレ(IST) | 月岡塗装店版(提案) |
|---|---|---|
| メインアクセント | `--accent:#1f5c3d`(深緑) | `--accent:#16406B`(ディープブルー) |
| 濃色(白文字用) | `--accent-d:#17472f` | `--accent-d:#0F2E4E` |
| 帯グラデ濃色 | `--accent-dd:#0e3122` | `--accent-dd:#081B30` |
| サブアクセント | `--accent-2:#a9703c`(テラコッタ) | **廃止**。ラベル・番号等は `--accent-mid:#5F86AC`(中間トーンの青)で代替 |
| 背景(紙) | `--bg:#faf7f2` | 同トーン維持(ニュートラルな紙色は青とも相性良好) |
| マーキー文字 | `--marquee-word:"IST BUILD"` | `"TSUKIOKA PAINT"` 等、社名ローマ字表記に差し替え |
| フォント(和文見出し) | Shippori Mincho | 維持 |
| フォント(筆記体ラベル) | Italianno | 維持 |
| フォント(巨大英字) | Anton | 維持 |
| フォント(本文) | Zen Kaku Gothic New | 維持 |

**インパクトを足すための調整方針**: ヒーロー・photo-divider等の写真は元テンプレより大判・高コントラストにトリミングし、暗幕(veil)をやや濃いめにして視認性と力強さを両立する。円形装飾(circle)は控えめに残しつつ、写真そのものの迫力を主役にする。

## 4. 構造上の主な特徴(パターンAとの違い)
- **右サイドレールナビ**: PC時はヘッダーが最小限(ロゴのみ)、右端に縦のレール(ハンバーガー・求人/お問い合わせアイコン・ページ上部へ戻るボタン)を常設
- **丸型固定CTA(fab)**: 右下に「お見積り・ご相談」の丸型ボタンを常設
- **スプラッシュ画面**: 初回訪問時にロゴマーク+マーキー1語+タグラインを表示してから本編へ
- **全画面メニューオーバーレイ**: ハンバーガータップで全画面メニュー。メインメニューとサブメニューの2階層構成
- **ページ見出し(page-hdr)**: 下層ページ共通で円形装飾+筆記体英字ラベル+タイトル+説明文
- **entrance(3分岐)**: TOPページに「お仕事のご依頼/施工実績を見る/一緒に働く」の3択導線(元テンプレの構造をそのまま活用)
- **alt(交互レイアウト)**: 写真とテキストを左右交互に配置する信頼訴求セクション
- **photo-divider**: 全幅の背景写真+一言メッセージで場面転換を挟む
- **merit(番号付き理由)**: 「選ばれる理由」を大きな数字(01/02/03/04)で見せる
- **FAQ(タブ+アコーディオン)**: カテゴリタブで質問を絞り込み、アコーディオンで開閉
