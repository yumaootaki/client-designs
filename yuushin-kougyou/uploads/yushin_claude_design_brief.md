# 株式会社ユウシン工業 サイトリプレイス Claude Design 用ブリーフ

以下の内容で、株式会社ユウシン工業のコーポレート兼採用サイト(14ページ)をデザインしてください。ページ構成とセクション順は同梱のワイヤーフレーム(yushin_wireframe.html)に従ってください。

## 1. 会社とサイトの目的

- 会社:株式会社ユウシン工業(埼玉県飯能市、創業2003年)
- 事業:鉄筋工事。鉄道・高速道路・橋脚(耐震補強)・浄水場・ポンプ場などの公共構造物。関東一円
- 強み:業歴35年のベテラン在籍、1級鉄筋施工技能士、公共工事の実績
- サイトの主目的:**鉄筋工の採用(次世代2〜3名)**。未経験・年齢不問
- サブ:元請けからの工事相談、協力会社募集
- 現URL:http://www.yushinkogyo.net/(リニューアルで SSL 化)

## 2. ターゲット

1. 未経験で手に職をつけたい20〜40代(メイン)
2. 経験者の鉄筋工・転職検討者
3. 飯能市周辺(入間・狭山・日高・所沢・青梅)+寮を使う遠方の求職者
4. 元請けのゼネコン・発注者(サブ)

## 3. トーン

- 誠実・実直・誇り。派手さより「信頼できる職人の会社」
- 言葉はやさしく平易に。専門用語は一言説明を添える
- 「見えなくなる仕事に誇りを持つ」が全体のテーマ

## 4. デザイントークン

| 役割 | 色 | 用途 |
|---|---|---|
| メイン(紺) | #1E3A5F | 見出し、ヘッダー、帯、フッター |
| 白 | #FFFFFF | 背景 |
| 差し色(オレンジ) | #F07A28 | 応募ボタン・CTA・タイムラインの点のみ |
| 薄グレー | #F3F5F8 | セクション背景の切り替え |
| 本文 | #1F2933 | 本文テキスト |
| 罫線 | #D5DCE5 | 表・カードの線 |
| LINE | #06C755 | LINEボタンのみ |

- オレンジは「押してほしい所」だけに使い、装飾には使わない
- フォント:見出し・本文とも Noto Sans JP(見出しは 700〜900)。数字(日給・年数)は大きく太く
- 写真が主役。現場の鉄筋(格子状の鉄筋が並ぶ画)を全体のモチーフにし、鉄筋の格子を薄い線パターンとして背景アクセントに使ってよい
- 角丸は小さめ(4px程度)。重い影は使わない

## 5. 共通パーツ

- ヘッダー:ロゴ/ナビ(求職者のみなさまへ・1日の流れ・スタッフ紹介・業務案内・施工実績・会社概要・よくある質問)/右端に「LINEで質問」(緑)「応募する」(オレンジ)
- スマホ:画面下に固定バー「電話する」「LINEで質問」「応募する」
- フッター:「働きたい方へ」「会社・工事について」の2列リンク、会社情報、TikTokリンク
- 全ページの最後に応募CTA(応募フォーム・LINE・電話)を置く。既存の応募導線は残す

## 6. ページ別の要点

### 1. TOP(/)
ヒーロー:現場写真 or 短尺動画+キャッチ「道路も、線路も、橋も。その中の鉄筋を組んでいます。」サブ「埼玉・飯能から関東一円の公共インフラを支える鉄筋工事会社です。未経験から一緒に働く仲間を募集しています。」ボタン:応募する/LINEで質問だけでもOK/電話する
→ 数字(創業2003年・業歴35年・1級技能士・完全週休2日・関東一円)→ こんな現場で働きます(4種)→ 1日の流れ抜粋 → 先輩の声3名 → 未経験からのステップ → 待遇ハイライト → TikTok動画 → 求職者のみなさまへバナー → 工事のご依頼の方へ(業務案内・施工実績)→ ブログ → 協力会社募集(1行)→ 最終CTA+地図+通勤圏

### 2. 業務案内(/work)
鉄筋工事とは(平易な説明+図解)→ 対応構造物4種(写真+説明)→ 施工の流れ → 体制と資格 → 工事のご相談CTA+採用小バナー

### 3. 採用情報(/recruit)
募集要項に特化。ヒーロー(応募ボタン3種)→ 募集要項表 → 応募から入社の流れ → 応募フォーム → 迷っている方へのリンク

### 4. 施工実績(/jisseki)
種類で絞り込み → 実績カード(写真・工事の種類・場所・規模・担当工程・ひとこと)→ 求職者CTA/工事相談CTAの2つ

### 5. 会社概要(/information)
会社情報表 → 代表メッセージ短縮版(顔写真)→「ユウシン工業について」へ → アクセス

### 6. ブログ(/blog)
カテゴリ(お知らせ・鉄筋工の仕事・現場レポート・採用・求人・協力会社)→ 記事一覧 → 記事下に採用バナー固定

### 7. お問い合わせ(/contact)
最初に目的を3択(働きたい・質問/工事のご相談/協力会社)→ 電話・LINE → フォーム

### 8. 求職者のみなさまへ(/recruit/message)※新規
ヒーロー「あなたが組んだ鉄筋が、何十年も街を支えます。」→ なぜ今仲間を募集するのか(次世代へ技術をつなぐ・もう1班つくる)→ 鉄筋工ってどんな仕事?(運ぶ・組む・確かめる・完成)→ 魅力3つ(地図に残る仕事/手に職・国家資格/顔が見える少人数)→ こんな人を待っています → 5ページへの振り分けカード → 募集要項へ

### 9. 1日の流れ(/recruit/day)※新規
写真つき縦タイムライン(集合 → 移動 → 朝礼・KY → 午前組立 → 昼休憩 → 午後組立・検査準備 → 片付け → 帰社)→「入社したばかりの人は運搬と結束の補助から」の強調ボックス → 大規模現場の写真3枚 → 現場の場所と移動

### 10. スタッフ紹介(/recruit/staff)※新規
集合写真 → 3名カード(業歴35年のベテラン/川村佑さん 2013年入社/32歳の次世代)→ インタビュー(きっかけ・うれしい時・大変なこと・未経験の人へ)×3 → TikTok動画 → 雰囲気写真4枚

### 11. 未経験から一人前まで(/recruit/career)※新規
ヒーロー「最初は運ぶことから。焦らなくて大丈夫です。」→ 成長ステップ(入社〜3ヶ月/〜1年/〜3年/職長)→ 取れる資格(費用全額会社負担)→ 給与の上がり方 → 教える体制

### 12. 働く環境・待遇(/recruit/environment)※新規
ヒーロー「完全週休2日。寮・社宅もあります。」→ 待遇6項目 → 寮・借り上げ社宅 → 通える範囲(地図+近隣市名)→ チームの雰囲気

### 13. よくある質問(/faq)※新規
タブ:働きたい方/工事・協力会社の方。アコーディオン形式の一問一答。回答は1〜2文で言い切る

### 14. ユウシン工業について(/about)※新規
ヒーロー「見えなくなる仕事に、手を抜かない。」→ 代表メッセージ(顔写真)→ あゆみ(2003年創業〜)→ 公共インフラを支える(4種)→ 次の世代へ(32歳の次世代からのメッセージ)

## 7. 確定している掲載情報

- 皆勤手当20,000円、賞与年2回
- 休日:完全週休2日

- 応募方法:応募フォーム/LINE/電話

## 8. ダミーのまま進める項目(お客様確認待ち)

勤務時間・集合時刻/雇用形態/社会保険/見学の可否/支援対象の資格一覧/昇給の仕組み/寮の場所・費用/沿革/代表・スタッフの氏名と写真/32歳の次世代スタッフの掲載可否/掲載できる現場写真の範囲/協力会社の募集条件

デザイン上は「〇〇」のプレースホルダーで配置し、レイアウトが崩れない文字量を想定してください。

## 9. 必須の実装要件

- スマホファースト(求職者の大半はスマホ)
- 応募ボタンは各ページで最低2か所+スマホ固定バー
- 構造化データ:JobPosting(採用情報)、FAQPage(FAQ)、Organization(会社概要)
- 既存URLからの301リダイレクトを前提にURLは /recruit/ 配下で整理
