## 見てほしい人

ゼネコン・サブコン・設備会社で、電気工事の協力会社を探している工事担当者・発注担当者。現場からスマホで見ることも多い。知りたいのは「この建物・この規模を任せられるか」「高圧も頼めるか」「エリア内か」「どう頼めばいいか」の4点。

## デザイン方針

### トーン
黒×赤のモノトーンで、シック・エレガント・落ち着き。現行コーポレートサイトの方向性を引き継ぐ。ただし**少し明るめ・読みやすさ優先**(お客様了承済み)。黒はメインビジュアル・ページヘッダー・CTA帯・フッターに限定し、本文エリアは白〜明るいグレーを基本にする。目安の比率は 白・明るいグレー60%/墨30%/赤10%。

### カラートークン

| 役割 | 色 | 使いどころ |
|---|---|---|
| 墨(メインダーク) | `#26272B` | メインビジュアル・ページヘッダー・CTA帯・フッター・見出し |
| 灰墨(サブダーク) | `#44464C` | ダーク面の中の区切り、サブ見出し |
| 紅(アクセント) | `#9E1B2C` | 細いライン、小見出しの印、数字、対応外工事の枠 |
| 紅・明(ボタン) | `#C42A3A` | CTAボタン、ホバー |
| ライトグレー | `#F1F2F3` | セクションの交互背景 |
| 白 | `#FFFFFF` | 本文エリア |
| 本文 / サブテキスト | `#2B2B2E` / `#6A6B70` | 文字 |
| 罫線 | `#DCDDE0` | 表・区切り |

赤は面で大きく使わず、線と点で効かせる(エレガントさを保つため)。

### タイポグラフィ
- 見出し:Shippori Mincho B1(600/700)。上品さと落ち着きを明朝で出す
- 本文・UI:Noto Sans JP(400/700)
- 本文 16px/行間 1.9、1行は全角40字前後まで
- 数字(業界歴26年など)は見出しと同じ明朝で大きく

### シグネチャー要素:ケーブル段剥ぎライン
高圧ケーブル端末処理の「段剥ぎ」(外装→遮へい→絶縁→導体)をモチーフにした横ラインを、サイト全体の目印にする。
- 4段の帯:墨(長)→灰墨→白(細い罫線で縁取り)→紅(短)
- 置き場所:メインビジュアル下、各ページのページヘッダー下、「高圧ケーブル端末処理」セクション
- それ以外では使わない(使いすぎない)
- ワイヤーフレーム内の `.cable` が形の参考

### 写真
- 実際の現場写真を使う前提。デモでは現行サイトの施工実績写真(57枚)から差し替え可能な仮画像、なければグレーのプレースホルダー
- メインビジュアルは代表が現場で作業している写真(手元と顔が分かるもの)。デモ時点で無ければ暗めのプレースホルダー+撮影予定と記載
- ストック写真の人物は使わない

### 動き
- ページ読み込み時にメインビジュアルのコピーとケーブル段剥ぎラインが1回だけ表示される演出のみ
- セクションごとのフェードインは入れない
- `prefers-reduced-motion` に対応

## 技術要件

- 全ページ作成。スマホ対応(ハンバーガーメニュー+画面下に「電話で相談」「工事のご相談」の2ボタン固定)
- Google Fonts(Shippori Mincho B1、Noto Sans JP)
- 構造化データ(JSON-LD):全ページに `Electrician`(LocalBusiness系)、FAQページに `FAQPage`(16問すべて)、パンくず `BreadcrumbList`
- 各ページの title / meta description はワイヤーフレームの「想定タイトル」をもとに設定
- お問い合わせフォームは見た目のみ(送信機能不要)。URLパラメータ `?type=ukeoi` / `?type=jouyou` で種別が選ばれた状態にする
- フッターに「一般のお客様(住宅の家電取付など)はこちら」→ https://www.cosmo-den.com/

## 文章の扱い

- ワイヤーフレームの文章をそのまま使う(要約・省略しない)
- 赤線のメモ(設計意図)はサイトに載せない
- 黄色マーカー(要確認)の項目は、デモでは「○○」などの仮表記のまま残し、確定後に差し替える
